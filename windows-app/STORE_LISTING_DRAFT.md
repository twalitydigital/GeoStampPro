## Description

Twality GeoStamp Pro is a free Windows desktop utility for photographers, field teams,
surveyors, documentation teams, and anyone who needs clean stamped copies of photos.

The app can print GPS coordinates, address information, timestamps, camera metadata,
additional EXIF details, and configurable text or image watermarks. It processes images
in batches, keeps the original files unchanged, and writes stamped copies to a dedicated
output folder.

Key features:

- Geo stamping with GPS coordinates, altitude, capture timestamp, address, and map.
- Optional stamping of additional EXIF information.
- Configurable text or image watermark with 3x3 placement, opacity, size, and inset.
- Preview first image before running a batch.
- Recursive folder processing.
- Pause, resume, cancel, progress, and per-file status reporting.
- JPEG metadata preservation through ExifTool.

Important notes:

- Geo Stamping requires GPS metadata in the source photo.
- Full metadata preservation is guaranteed only for JPEG outputs.
- Reverse geocoding and map display may require internet access.
- ExifTool must be installed and available on PATH for full JPEG metadata restoration.
