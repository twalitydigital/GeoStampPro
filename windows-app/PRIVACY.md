# Privacy Notice for Twality GMark Pro 1.0

Twality GMark Pro is a desktop utility by Twality Digital Solutions LLP for stamping
photos with geo, EXIF, and watermark information.

## Summary

- The app runs locally on the user's Windows device.
- The app does not require sign-in.
- The app does not include advertising.
- The app does not sell personal data.
- Original source images are not intentionally modified; stamped output is written as
  copies.

## Data Processed Locally

The app reads image files selected by the user and may process:

- file paths and file names;
- image pixels;
- EXIF metadata, including camera data, timestamps, and GPS coordinates when present;
- user-selected watermark text or watermark image path;
- app settings stored locally in the app runtime data folder;
- local cache files for reverse geocoding and map data.

## Network Use

When Geo Stamping is enabled and a photo contains GPS coordinates, the app may contact
OpenStreetMap Nominatim to reverse geocode coordinates into an address. The request may
include latitude, longitude, language preference, and a user-agent identifying the app.

The app may also download map imagery or map-related data through its configured map
provider.

## Data Sharing

Twality GMark Pro does not transmit image files to Twality Digital Solutions LLP.
Network requests used for reverse geocoding or maps are sent only to the configured
external service providers needed to perform those features.

## User Control

Users control which folders and images are processed. Users can disable Geo Stamping,
All Additional EXIF Data stamping, and Print Watermark independently in the app.

## Data Retention

The app stores settings, logs, and cache files locally on the user's device. In packaged
Windows builds, these files are stored under the user's LocalAppData folder for Twality
GMark Pro. Users can delete these files if they want to reset local state.
